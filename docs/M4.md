# M4 – Workspace

Implemented first stage: geometry editor in millimetres, draggable canvas and service zones, numeric position and dimension editing, automatic paint containers linked to the active palette, water, wipe, parking, and removable forbidden rectangles. Origin is top-left, X right, Y down; future machine-coordinate conversion must be explicit.

Project format v8 stores the layout. Versions 1–7 migrate with a default workspace. Existing paint positions survive palette edits; canvas dimensions follow Image settings. Layout validation reports zone overlaps and zones outside the machine area and blocks Continue while issues exist.

Verified with build and tests for persistence, migration, palette synchronization, overlaps, invalid data and bounds.

Remaining M4 work: build the complete machine-space plan from strokes, schedule paint loads and cleaning/wiping, model paint capacity, route safe travel around forbidden zones, and validate full brush clearance. Current layout checks do not guarantee collision-free machine motion. Simulation and export remain separate future steps.
