# M0 – technický průzkum a referenční průchod

## Potvrzená rozhodnutí

- Cílová architektura je Tauri + React/TypeScript + Rust jádro.
- Node.js je pouze vývojový a sestavovací nástroj; nebude součástí běhové distribuce aplikace.
- React obsluhuje UI. Canvas 2D, případně WebGL, zobrazuje náhledy, vrstvy a animaci.
- Rust vlastní plná obrazová data a provádí obrazové zpracování, geometrii, plánování, validaci a export.
- Pro velké vstupy, typicky až 3000 × 4000 px, používá UI zmenšený interaktivní náhled. Plné rozlišení se zpracovává asynchronně v Rustu a mezivýsledky se ukládají do cache.
- Přes hranici Tauri se neposílají opakovaně celé pixelové buffery; UI předává parametry a přijímá náhled nebo odkaz na připravený výsledek.
- První doménový prototyp je záměrně v TypeScriptu bez závislostí. Ověřuje hranici mezi malířským plánem, validací a postprocesorem; po instalaci Rust toolchainu lze stejné typy přenést do jádra.
- Referenční stroj pro prototyp je kartézský XYZ plotter s GRBL. Přítlak `0–1` se lineárně mapuje na pracovní rozsah Z.
- Souřadnice plánu a profilu jsou v milimetrech; G-code používá absolutní souřadnice.

Parametry referenčního stroje jsou nadále pracovní předpoklady, ne potvrzené parametry skutečného hardwaru.

## Referenční scénář

`src/demo.ts` vytvoří jeden modrý tah z bodu `(20, 30)` do `(100, 80)`, obklopí jej bezpečným zvednutím nástroje a zaparkováním. Postprocesor před exportem odmítne souřadnice mimo pracovní rozsah, neplatnou rychlost a přítlak.

Spuštění na Node.js 24+:

```powershell
npm.cmd test
npm.cmd run demo
```

## Co zbývá k uzavření M0

1. Potvrdit XY + servo versus XYZ a význam osy Z.
2. Doplnit rozměry stroje, bezpečné Z a parkovací bod.
3. Vybrat první štětec, barvu a podklad.
4. Dodat 2–3 referenční obrázky a očekávaný charakter výstupu.
5. Rozhodnout, zda jsou voda a otírání ve stejném pracovním prostoru.
6. Nainstalovat Rust toolchain a ověřený model převést do samostatného Rust crate.

Akceptační řetězec M0 je nyní spustitelný jako `PaintingPlan → validatePlan → toGrbl`; fyzické parametry je ještě nutné potvrdit.
