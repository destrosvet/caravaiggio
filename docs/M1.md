# M1 – kostra aplikace a projektový formát

## Hotové části

- Tauri 2 desktopový shell s React/TypeScript aplikací a základní navigací pracovního postupu.
- Založení nového projektu a změna jeho názvu.
- Import PNG nebo JPEG včetně rozměrů a náhledu.
- Nastavení fyzické šířky a výšky plátna v milimetrech.
- Nativní dialogy pro uložení a otevření projektu; webový režim používá bezpečný fallback prohlížeče.
- Uložení projektu včetně vloženého obrázku do přenosného JSON souboru.
- Otevření projektu s kontrolou identity, rozměrů, časových razítek a obrazových dat.
- Verzovaný formát `caravaiggio-project`; aktuální verze je 2.
- Automatická migrace projektu verze 1 na verzi 2, která explicitně ukládá jednotku plátna.
- Akceptační test potvrzuje zachování obrázku a rozměrů po serializaci a otevření.
- Ochrana neuložených změn při založení či otevření jiného projektu a při zavření okna.

## Co zbývá k úplnému uzavření M1

1. Ověřit zavření a opětovné spuštění nainstalované desktopové aplikace.

Desktopový shell, projektový formát i Windows NSIS balíček jsou sestavitelné. Zbývá uživatelský instalační a restartovací test.
